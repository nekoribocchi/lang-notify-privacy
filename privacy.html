Lang Notify（以下「本アプリ」）は、学習記録と通知機能を提供するにあたり、利用者の情報を適切に取り扱います。このポリシーは、アカウント、クラウド同期、AI機能、広告および本サイトでの削除申請に関する情報を説明します。

アカウントを削除する場合： アカウント削除ページからメール確認を行って申請してください。Google Play の定期購入は自動解約されません。お問い合わせは nekoribocchi@gmail.com まで。

1. 取り扱う情報と利用目的

  • アカウント情報：メールアドレス、認証・セッション情報。ログイン、本人確認、アカウント管理のために Supabase Auth で処理します。
  • Premium のクラウドデータ：利用者が同期を有効にした単語・学習データと購入権限の確認に必要な情報。端末間同期、Premium 機能の提供、不正利用防止に使います。
  • AI機能の利用情報：入力した単語、言語、任意のニュアンス指示をAI翻訳に利用します。AI翻訳を実行すると、この入力内容が OpenAI API に送信されます。利用上限と不正利用を管理するため、匿名化したアカウント・端末・セッション・IPの照合値と利用回数も処理します。
  • 通常のFreeデータ：通常のFree単語、累計60件の利用台帳、端末内AI利用上限は端末内に保存され、アカウントに紐づきません。
  • 広告関連情報：Free版の広告表示に Google Mobile Ads SDK と Google の同意管理（UMP）を使います。SDKは広告の配信・測定、診断、不正利用防止のため、IPアドレス、アプリ内操作、診断情報、端末またはアカウント識別子などを収集・共有する場合があります。広告に関する選択肢は、地域や設定に応じてアプリ内で表示します。
  • 本サイトのアクセス情報：本サイトのホスティングに GitHub Pages を使用します。GitHub はサービス運用・セキュリティのため、アクセス時にIPアドレス等の技術情報を処理する場合があります。

2. Firebase Analytics

現在のアプリには Firebase Analytics を組み込んでいません。将来利用を開始する場合は、実際の収集内容に合わせてこのポリシーと Google Play の Data safety 情報を更新します。

3. 外部サービスとの共有

認証とクラウド保存に Supabase、AI翻訳に OpenAI API、広告に Google Mobile Ads を利用します。AI翻訳を実行すると、入力した単語、翻訳先の言語、任意のニュアンス指示をOpenAIへ送信します。各サービスはそれぞれのプライバシー方針に従って情報を処理します。広告 SDK の情報については Google Mobile Ads の Data safety 開示をご確認ください。

4. 保存期間

アカウント削除が確定すると、アカウント、Premiumクラウドデータ、購入権限情報、アカウントに紐づくAI利用情報の削除を開始します。削除処理のためのバックアップは最長30日で失効します。法令上の会計・税務・返金・不正対策記録など、保持が必要な最小限の情報は、適用される期間だけ保存する場合があります。セキュリティや集計のための情報は、個人を直接特定しない形で必要な期間に限り保存する場合があります。

5. アカウント削除

削除ページでメールアドレスを確認し、本人が最終確認を行うと削除申請が完了します。登録の有無は申請画面の応答から判別できないようにしています。削除後も、端末内だけに保存された通常のFreeデータは端末に残ります。また、Google Play の定期購入は自動解約されないため、利用者自身で Google Play の定期購入管理画面から解約してください。

6. 子どものプライバシー

本アプリは、適用される年齢・同意要件に従って利用してください。保護者の同意が必要な地域では、必要な同意を得てからご利用ください。

7. 安全管理とポリシーの変更

情報へのアクセスを必要な範囲に限定し、合理的な安全対策を講じます。機能、法令または外部サービスの変更に応じて本ポリシーを更新し、このページに掲載します。
